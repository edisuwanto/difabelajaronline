Bagian 1 — Deep Learning dalam AI Engineering

Pada pertemuan sebelumnya kita sudah belajar bahwa Machine Learning memungkinkan komputer mempelajari pola dari data. Sekarang kita naik satu tingkat.

Deep Learning merupakan salah satu bagian dari Machine Learning yang menggunakan neural network dengan banyak lapisan untuk mempelajari pola dari data.

Hubungannya dapat digambarkan seperti ini:

Artificial Intelligence
        ↓
Machine Learning
        ↓
Deep Learning
        ↓
Neural Network

Jadi Deep Learning bukan teknologi yang berdiri sendiri di luar Machine Learning.

Deep Learning adalah salah satu pendekatan dalam Machine Learning.

Deep Learning menjadi sangat penting dalam perkembangan AI modern karena dapat digunakan untuk berbagai jenis pekerjaan, seperti:

  • pengenalan suara,
  • pengenalan gambar,
  • pemrosesan bahasa,
  • penerjemahan,
  • analisis teks,
  • computer vision,
  • speech recognition,
  • generative AI.

Namun pada pertemuan ini kita tidak akan membuat model sebesar model AI modern seperti LLM. Kita akan membuat model neural network sederhana agar memahami prinsip dasarnya.

Analogi Deep Learning untuk Tunanetra

Bayangkan Anda belajar mengenali berbagai bentuk uang logam. Awalnya Anda hanya mengenali ukuran (Machine Learning dasar). Namun seiring berjalannya waktu, Anda mulai meraba tekstur pinggiran, ketebalan, dan beratnya sekaligus secara mendalam (Deep Learning) sehingga Anda bisa mengenali koin tersebut dengan jauh lebih akurat dan cepat.

Bagian 2 — Analogi Neural Network

Untuk memahami neural network, bayangkan sebuah sistem yang terdiri dari beberapa orang yang saling meneruskan informasi.

Orang pertama menerima informasi.

Kemudian informasi diteruskan kepada orang kedua.

Orang kedua memproses informasi tersebut dan meneruskannya lagi.

Setelah melewati beberapa orang, akhirnya informasi sampai kepada orang terakhir yang menghasilkan keputusan.

Neural network memiliki konsep yang mirip.

Input
  ↓
Layer
  ↓
Layer
  ↓
Output

Setiap bagian memiliki tugas dalam proses pengolahan informasi.

Analogi Neural Network untuk Tunanetra

Untuk mempermudah pemahaman, mari kita gunakan analogi yang relevan bagi tunanetra. Bayangkan Anda sedang berusaha mengenali sebuah benda hanya dengan merabanya.

  • Input Layer: Kulit di ujung jari Anda menyentuh benda tersebut. Jari-jari bertugas mengumpulkan informasi dasar, seperti tekstur (kasar atau halus) dan bentuk permukaan.
  • Hidden Layer: Informasi dasar dari jari diteruskan melalui jaringan saraf ke otak. Di tahap ini (lapisan tersembunyi), informasi digabungkan dan diproses secara bertingkat. Otak Anda mulai merangkai pola bahwa "benda ini bulat, permukaannya berpori, dan seukuran kepalan tangan".
  • Output Layer: Bagian akhir dari otak Anda mengambil kesimpulan dari semua rangkaian informasi tersebut dan memutuskan: "Ini adalah buah jeruk".

Dalam Neural Network, setiap "layer" (lapisan) bekerja persis seperti proses meraba dan mengenali tersebut. Lapisan-lapisan itu saling mengoper dan mengolah informasi dari bagian yang paling sederhana hingga menghasilkan sebuah prediksi atau keputusan akhir yang utuh.

Bagian 3 — Apa Itu Neuron?

Neuron merupakan unit dasar dalam neural network.

Kita dapat membayangkannya sebagai sebuah unit pengolah informasi.

Neuron menerima beberapa nilai input, mengolahnya, kemudian menghasilkan output.

Contohnya kita mempunyai dua informasi:

  • Jam belajar
  • Jumlah latihan

Informasi tersebut diberikan kepada neural network.

Jam belajar ─────┐
                ↓
             Neuron
                ↑
Jumlah latihan ─┘

Neuron kemudian menghasilkan sebuah nilai.

Dalam neural network sebenarnya terdapat proses matematika di dalam neuron. Namun untuk pemula, kita tidak perlu langsung mempelajari rumusnya secara mendalam.

Yang perlu dipahami terlebih dahulu:

Neuron menerima input, melakukan perhitungan, kemudian menghasilkan output.

Analogi Neuron untuk Tunanetra

Bayangkan neuron sebagai satu titik peka pada ujung jari Anda saat meraba huruf Braille. Satu titik tersebut mendeteksi ada tidaknya tonjolan (input). Saraf di titik tersebut merespon (perhitungan) dan mengirimkan sinyal rasa (output) ke otak. Masing-masing titik ujung jari (neuron) bekerja menangkap informasi kecil yang spesifik.

Bagian 4 — Apa Itu Layer?

Neuron biasanya disusun dalam kelompok yang disebut layer atau lapisan.

Secara sederhana terdapat:

1. Input Layer

Menerima data.

2. Hidden Layer

Memproses informasi.

3. Output Layer

Menghasilkan hasil akhir.

Gambaran sederhananya:

Input Layer
     ↓
Hidden Layer
     ↓
Hidden Layer
     ↓
Output Layer

Disebut Deep Learning karena neural network dapat memiliki banyak layer.

Semakin banyak dan kompleks lapisan yang digunakan, semakin kompleks pula pola yang dapat dipelajari model.

Tetapi semakin kompleks model, biasanya semakin besar pula kebutuhan data, komputasi, dan proses training.

Analogi Layer untuk Tunanetra

Layer bisa diibaratkan sebagai tahapan saat Anda mengenali sebuah ruangan baru. Lapisan pertama (Input Layer) adalah saat tongkat Anda menyentuh lantai. Lapisan kedua (Hidden Layer) adalah saat pendengaran Anda menangkap gema suara di ruangan dan menggabungkannya dengan perasaan langkah kaki. Lapisan ketiga (Output Layer) adalah kesimpulan akhir di otak Anda yang menyatukan semua itu: "Ini adalah ruangan aula yang luas".

Bagian 5 — Input, Hidden Layer, dan Output

Mari kita gunakan contoh klasifikasi sederhana.

Kita ingin memprediksi apakah seorang siswa lulus atau tidak lulus.

Data yang diberikan:

  • Jam belajar
  • Jumlah latihan

Maka:

Input:
Jam belajar
Jumlah latihan

Neural network memproses data tersebut.

Kemudian output:

Lulus

atau:

Tidak Lulus

Alurnya:

Jam belajar
Jumlah latihan
       ↓
 Input Layer
       ↓
 Hidden Layer
       ↓
 Output Layer
       ↓
Lulus / Tidak Lulus

Analogi Input, Hidden Layer, dan Output untuk Tunanetra

Proses ini mirip dengan menyeduh secangkir kopi. Input Layer: Anda menyiapkan kopi bubuk dan air panas ke dalam cangkir. Hidden Layer: Anda mengaduknya agar larut merata dan menyatu sempurna, proses yang tidak terlihat tapi menyatukan rasa. Output Layer: Anda mencicipi dan merasakan secangkir kopi yang siap dinikmati.

Bagian 6 — Apa yang Dipelajari Model?

Pertanyaan pentingnya:

Kalau model tidak kita beri aturan secara langsung, lalu apa yang sebenarnya dipelajari?

Model belajar menemukan pola dalam data.

Misalnya kita memiliki data:

Jam Belajar | Latihan | Status
1           | 1       | Tidak Lulus
2           | 1       | Tidak Lulus
3           | 2       | Tidak Lulus
5           | 4       | Lulus
6           | 5       | Lulus
7           | 6       | Lulus

Model mencoba menemukan pola hubungan antara input dan output.

Ketika diberikan data baru:

Jam belajar = 6
Latihan = 4

model dapat menghasilkan prediksi.

Analogi untuk Tunanetra

Model belajar menemukan pola sama seperti Anda belajar mengenali rute jalan menuju taman. Awalnya mungkin Anda sesekali salah belok (kesalahan prediksi), tapi setelah berkali-kali melewati jalan yang sama sambil mengingat jumlah langkah dan arah belokan, Anda akhirnya menemukan pola yang tepat. Saat berjalan kembali, Anda bisa memprediksi dengan tepat kapan harus belok kiri atau kanan.

Bagian 7 — Training

Training adalah proses ketika model belajar dari data.

Secara sederhana:

Dataset
   ↓
Neural Network
   ↓
Prediksi
   ↓
Bandingkan dengan jawaban
   ↓
Perbaiki parameter
   ↓
Training berikutnya

Proses tersebut dilakukan berulang kali.

Model mencoba menghasilkan prediksi.

Kemudian hasilnya dibandingkan dengan jawaban yang benar.

Jika hasilnya masih salah, parameter model diperbaiki.

Proses ini terus dilakukan sampai model mendapatkan hasil yang lebih baik berdasarkan tujuan training.

Analogi Training untuk Tunanetra

Training mirip dengan belajar memainkan alat musik, misalnya piano. Saat Anda meraba dan menekan tuts, guru Anda akan memberitahu apakah nada tersebut benar atau salah (membandingkan dengan jawaban). Jika salah, Anda memperbaiki posisi jari Anda dan mencoba lagi (memperbaiki parameter). Proses ini diulang terus-menerus hingga Anda bisa memainkan lagu dengan lancar tanpa salah nada.

Bagian 8 — Epoch

Dalam Deep Learning kita akan menemukan istilah epoch.

Epoch adalah satu putaran ketika seluruh data training digunakan untuk melatih model.

Misalnya kita memiliki:

100 data

Jika model memproses seluruh 100 data tersebut satu kali, itu dapat disebut:

1 epoch

Jika dilakukan 10 kali:

10 epoch

Contohnya:

Epoch 1 → Model belajar
Epoch 2 → Model belajar lagi
Epoch 3 → Model belajar lagi
...
Epoch 10 → Model belajar lagi

Namun lebih banyak epoch tidak selalu berarti model menjadi lebih baik. Jika terlalu lama dilatih terhadap data tertentu, model dapat mengalami overfitting.

Untuk pertemuan ini kita cukup memahami konsep epoch secara sederhana.

Analogi Epoch untuk Tunanetra

Epoch ibarat membaca sebuah buku Braille dari awal sampai akhir. Satu Epoch berarti Anda telah selesai meraba dan membaca seluruh halaman di buku tersebut. Membaca berulang kali (banyak epoch) membuat Anda lebih mengingat dan memahami ceritanya. Tapi jika terlalu sering membaca buku yang persis sama, Anda mungkin hanya akan menghafal urutan letak titiknya tanpa sungguh-sungguh memahami maknanya (overfitting).

Bagian 9 — Inference

Setelah model selesai dilatih, kita dapat menggunakannya untuk data baru.

Proses menggunakan model yang sudah dilatih disebut inference.

Alurnya:

Training Data
      ↓
Training
      ↓
Model
      ↓
Data Baru
      ↓
Inference
      ↓
Prediksi

Contohnya:

Training:
Data siswa sebelumnya

Model:
Belajar pola

Inference:
Siswa baru

Hasil:
Prediksi Lulus

Jadi jangan mencampur:

  • Training = proses belajar.
  • Inference = menggunakan model yang sudah belajar.

Analogi Inference untuk Tunanetra

Inference ibarat menjalani ujian praktik. Setelah berminggu-minggu berlatih (training) meraba berbagai rute di lingkungan sekolah, kini saatnya Anda diuji berjalan di sebuah rute baru yang mirip namun belum pernah Anda lewati. Kemampuan Anda menebak kapan harus berbelok dengan lancar menggunakan keahlian yang telah dilatih sebelumnya, itulah proses inference.

Bagian 10 — Activation Function

Di dalam neural network terdapat komponen yang disebut activation function.

Activation function membantu neural network menentukan bagaimana sebuah nilai diteruskan dari satu bagian jaringan ke bagian lainnya.

Beberapa activation function yang sering ditemukan:

  • ReLU.
  • Sigmoid.
  • Tanh.
  • Softmax.

Untuk pemula, cukup pahami bahwa activation function merupakan salah satu komponen penting yang membuat neural network mampu memproses pola yang lebih kompleks.

Contohnya dalam Python:

from tensorflow.keras.layers import Dense

Dense(16, activation="relu")

Artinya kita membuat sebuah layer dengan 16 unit dan menggunakan fungsi aktivasi ReLU.

Kita tidak perlu membahas rumus ReLU pada pertemuan ini.

Analogi Activation Function untuk Tunanetra

Activation function ibarat sebuah pintu saringan bagi indera peraba Anda. Misalnya saat Anda meraba meja mencari koin logam. Jari Anda menyaring sentuhan: jika benda itu berbahan kertas yang rata, jari Anda akan mengabaikannya (informasi ditahan). Namun jika benda itu terasa bulat dan keras, jari Anda akan merespons kuat (informasi diteruskan). Pintu saringan inilah yang menentukan informasi penting mana yang akan dilanjutkan ke otak.

Bagian 11 — Praktik: Membuat Neural Network Sederhana

Sekarang kita masuk praktik.

Kita akan menggunakan TensorFlow dan Keras.

Install terlebih dahulu:

pip install tensorflow

Kemudian buat file:

deep_learning.py

Masukkan kode berikut:

import numpy as np
from tensorflow import keras
from tensorflow.keras import layers

X = np.array([
    [1, 1],
    [2, 1],
    [3, 2],
    [5, 4],
    [6, 5],
    [7, 6]
], dtype=float)

y = np.array([
    0,
    0,
    0,
    1,
    1,
    1
], dtype=float)

model = keras.Sequential([
    layers.Dense(8, activation="relu", input_shape=(2,)),
    layers.Dense(1, activation="sigmoid")
])

model.compile(
    optimizer="adam",
    loss="binary_crossentropy",
    metrics=["accuracy"]
)

model.fit(X, y, epochs=50, verbose=0)

hasil = model.predict(
    np.array([[6, 4]], dtype=float),
    verbose=0
)

print("Probabilitas:", hasil[0][0])

if hasil[0][0] >= 0.5:
    print("Prediksi: Lulus")
else:
    print("Prediksi: Tidak Lulus")

Bagian 13 — Melatih Model

Bagian paling penting adalah:

model.fit(X, y, epochs=50, verbose=0)

fit() digunakan untuk melakukan training.

Kita memberikan:

  • X = data input
  • y = jawaban
  • epochs = jumlah putaran training

Setelah training selesai, model sudah memiliki pola yang dipelajari dari data training.

Bagian 14 — Melakukan Prediksi

Sekarang kita memberikan data baru:

[[6, 4]]

Artinya:

  • Jam belajar = 6
  • Jumlah latihan = 4

Kemudian:

hasil = model.predict(
    np.array([[6, 4]], dtype=float),
    verbose=0
)

Model menghasilkan sebuah nilai probabilitas.

Kemudian program memeriksa:

if hasil[0][0] >= 0.5:
    print("Prediksi: Lulus")
else:
    print("Prediksi: Tidak Lulus")

Analogi Membangun dan Melatih Model untuk Tunanetra

Langkah-langkah dalam praktik dari Bagian 11 hingga 14 mirip dengan membuat kerajinan anyaman bambu. Menyiapkan array X dan y ibarat menyiapkan potongan bambu (bahan baku). Fungsi Sequential() dan compile() ibarat menyusun kerangka dan menentukan pola anyaman (persiapan). Lalu, fit() adalah proses Anda menganyam berulang-ulang, memperbaiki bagian yang kurang rapat (training). Terakhir, predict() adalah saat Anda menguji memasukkan barang ke keranjang anyaman Anda untuk memastikan seberapa rapi dan kuatnya keranjang tersebut (inference).
