Salah satu teknologi yang mendukung proses ini adalah:

Gemini Canvas

Apa Itu Gemini Canvas?

Gemini Canvas adalah fitur pada Gemini yang memungkinkan pengguna membuat, mengembangkan, dan memodifikasi berbagai jenis konten secara interaktif, termasuk kode website.

Gemini Canvas dapat membantu:

  • Menulis kode HTML
  • Menulis CSS
  • Menulis JavaScript
  • Membuat struktur website
  • Memperbaiki kode
  • Mengembangkan fitur website

Keunggulan Gemini Canvas

Cepat

Website dapat dibuat dalam hitungan menit.

Mudah Digunakan

Cukup menggunakan bahasa sehari-hari.

Cocok untuk Pemula

Tidak harus menjadi programmer profesional.

Dapat Dimodifikasi

Kode hasil AI dapat diedit kembali sesuai kebutuhan.

Mendukung Produktivitas

Mengurangi waktu pengembangan website.

Kapan Menggunakan Gemini Canvas?

Landing Page

Untuk promosi produk atau layanan.

Website Profil

Untuk individu atau organisasi.

Website Pendidikan

Untuk sekolah dan lembaga pelatihan.

Website UMKM

Untuk memperkenalkan produk dan layanan.

Website Portofolio

Untuk menampilkan hasil karya dan pengalaman.

STRUKTUR WEBSITE MODERN

Apa Itu Struktur Website?

Struktur website adalah susunan bagian-bagian yang membentuk sebuah website.

Website yang baik harus memiliki struktur yang jelas agar mudah digunakan oleh pengunjung.

Komponen Utama Website

Header

Bagian atas website.

Biasanya berisi:

  • Logo
  • Nama website
  • Menu navigasi

Hero Section

Bagian pertama yang dilihat pengunjung.

Berisi:

  • Judul utama
  • Deskripsi singkat
  • Tombol aksi (Call To Action)

About Section

Berisi informasi tentang:

  • Organisasi
  • Produk
  • Layanan

Services Section

Berisi daftar layanan atau program.

Gallery Section

Berisi gambar atau dokumentasi.

Contact Section

Berisi informasi kontak.

Footer

Bagian bawah website.

Biasanya berisi:

  • Hak cipta
  • Alamat
  • Media sosial

Contoh Struktur Landing Page

  1. Header
  2. Hero Section
  3. Keunggulan
  4. Testimoni
  5. Call To Action
  6. Footer

STRUKTUR WEBSITE YANG AKSESIBEL

Sebagai pengembang website modern, aksesibilitas harus menjadi perhatian utama.

Website harus dapat digunakan oleh:

  • Tunanetra
  • Low Vision
  • Lansia
  • Pengguna screen reader

Prinsip Dasar Aksesibilitas

Gunakan Heading yang Benar

Contoh:

<h1>Judul Utama</h1>
<h2>Sub Judul</h2>
<h3>Bagian</h3>

Gunakan Teks Alternatif Gambar

Contoh:

<img src="foto.jpg" alt="Peserta pelatihan AI sedang belajar menggunakan laptop">

Gunakan Tombol yang Jelas

Contoh:

<button>Daftar Sekarang</button>

Gunakan Warna yang Memiliki Kontras Baik

Agar mudah dibaca.

Pastikan Dapat Diakses dengan Keyboard

Tanpa harus menggunakan mouse.

PROMPT UNTUK MEMBUAT WEBSITE

Mengapa Prompt Penting?

Gemini membuat website berdasarkan instruksi yang diberikan.

Semakin jelas prompt, semakin baik hasilnya.

Struktur Prompt Website

Gunakan formula:

Tujuan + Jenis Website + Fitur + Desain + Teknologi

Contoh Prompt Dasar

Buat website profil sekolah menggunakan HTML dan CSS.

Contoh Prompt Menengah

Buat website profil organisasi sosial menggunakan HTML, CSS, dan JavaScript. Website memiliki halaman beranda, profil, program, galeri, dan kontak.

Contoh Prompt Profesional

Anda adalah web developer profesional. Buat website profil organisasi Tunanetra dengan desain modern dan responsif menggunakan HTML, CSS, dan JavaScript. Website memiliki header, hero section, profil lembaga, program pendidikan, galeri kegiatan, formulir kontak, dan footer. Pastikan website ramah screen reader dan mengikuti prinsip aksesibilitas web.

TEKNIK MEMODIFIKASI WEBSITE HASIL AI

Mengubah Warna

Prompt:

Ubah warna utama website menjadi biru dan putih.

Mengubah Layout

Prompt:

Ubah tampilan menjadi lebih modern dengan desain satu halaman.

Menambahkan Fitur

Prompt:

Tambahkan formulir pendaftaran online.

Menambahkan Galeri

Prompt:

Tambahkan galeri gambar dengan tampilan grid.

Menambahkan Animasi

Prompt:

Tambahkan animasi sederhana saat pengguna menggulir halaman.
