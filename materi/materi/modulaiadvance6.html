Building an Intelligent AI Dictionary Chatbot with Python
Penerapan Natural Language Processing & Pembuatan Chatbot Cerdas Langkah demi Langkah

Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta mampu:

  • Memahami perbedaan mendasar antara pencarian kata persis (*exact matching*) dan pemrosesan kalimat bebas (*Natural Language Processing / NLP*).
  • Menerapkan teknik pembersihan teks dan pemotongan kata (*tokenisasi*) sederhana di Python menggunakan fungsi bawaan .split() dan .replace().
  • Menyusun basis data kamus terstruktur yang kaya (*nested dictionary*) berisi arti, kelas kata (*part of speech*), dan contoh kalimat lengkap.
  • Membangun fungsi pemindai kata kunci cerdas (*keyword extraction*) untuk menemukan kata inti di dalam kalimat percakapan pengguna.
  • Menerapkan deteksi niat percakapan (*intent recognition*) sederhana untuk merespons salam dan sapaan ramah.
  • Memahami konsep integrasi model AI Generatif (LLM) untuk menjawab kata-kata baru yang belum tercatat di kamus lokal secara otomatis.
  • Mempersiapkan lingkungan koding (mengecek Python, memahami kebutuhan library, membuat file proyek, dan menjalankan kode di terminal).
  • Mempraktikkan kode program secara mandiri dengan antarmuka yang sangat ramah terhadap pembaca layar (*screen reader* NVDA / JAWS).

Pengantar — Dari Chatbot Kaku Menuju Chatbot Cerdas

Pada Topik 5 sebelumnya, kita telah berhasil membangun fondasi chatbot kamus pertama menggunakan bahasa Python. Program tersebut bekerja dengan cara memeriksa kecocokan persis antara input pengguna dan kata di dalam kamus: 

if kata in kamus:
    print("Arti", kata, "adalah", kamus[kata])

Namun, ada satu kelemahan besar pada chatbot tersebut: program sangat kaku. Jika pengguna mengetik satu kata saja seperti house, program bisa menjawab. Tetapi jika pengguna mengetik kalimat wajar manusia seperti: 

"Halo chatbot, apa arti kata house?"

Chatbot Topik 5 akan bingung dan menjawab: "Maaf, kata tersebut belum tersedia di kamus." Mengapa demikian? Karena program mencari teks lengkap "Halo chatbot, apa arti kata house?" di dalam database, bukan mencari kata intinya.

Pada Topik 6 ini, kita akan melengkapi chatbot kita dengan kecerdasan buatan (AI) sederhana agar mampu membedah kalimat pengguna, mengenali kata kuncinya secara otomatis, dan memberikan jawaban yang lengkap serta ramah.

Itulah yang akan kita ajarkan kepada komputer pada materi ini menggunakan logika pemrograman Python yang terstruktur dan mudah dipelajari.

Bagian 1 — Konsep Natural Language Processing (NLP) Sederhana

Natural Language Processing (NLP) adalah bidang dalam kecerdasan buatan yang memungkinkan komputer memahami, mengolah, dan merespons bahasa manusia secara alami.

Untuk membuat chatbot kita cerdas tanpa perlu pustaka eksternal yang rumit, kita dapat menerapkan 3 langkah utama NLP dasar di Python:

1. Normalisasi Teks (Text Normalization)

Mengubah seluruh karakter menjadi huruf kecil menggunakan .lower() dan membersihkan tanda baca seperti tanda tanya (?), titik (.), atau tanda seru (!).

2. Pemotongan Kata / Tokenisasi (Tokenization)

Memecah sebuah kalimat panjang menjadi daftar potongan kata (*tokens*) menggunakan fungsi .split(). 

kalimat = "apa arti kata school"
kata_kata = kalimat.split()
# Hasilnya: ['apa', 'arti', 'kata', 'school']

3. Ekstraksi Kata Kunci (Keyword Extraction)

Memeriksa setiap kata hasil pecahan tersebut ke dalam database kamus kita untuk menemukan kata kunci yang dicari.

Bagian 2 — Struktur Data Kamus yang Kaya (Nested Dictionary)

Di Topik 5, kamus kita hanya menyimpan sebaris teks arti sederhana. Sekarang, kita ingin chatbot memberikan informasi selayaknya kamus pintar: ada arti kata, kelas kata (*noun, verb, adjective*), dan contoh kalimat praktis.

Dalam Python, kita bisa menyusun *dictionary* di dalam *dictionary* (*nested dictionary*): 

kamus_ai = {
    "house": {
        "arti": "rumah",
        "tipe": "kata benda (noun)",
        "contoh": "This is a big house.",
        "arti_contoh": "Ini adalah rumah yang besar."
    },
    "book": {
        "arti": "buku",
        "tipe": "kata benda (noun)",
        "contoh": "I love reading this book.",
        "arti_contoh": "Saya suka membaca buku ini."
    },
    "learn": {
        "arti": "belajar",
        "tipe": "kata kerja (verb)",
        "contoh": "We learn AI Engineering together.",
        "arti_contoh": "Kita belajar AI Engineering bersama-sama."
    },
    "beautiful": {
        "arti": "indah atau cantik",
        "tipe": "kata sifat (adjective)",
        "contoh": "She has a beautiful voice.",
        "arti_contoh": "Dia memiliki suara yang merdu dan indah."
    }
}

Dengan struktur ini, saat kata "house" ditemukan, chatbot dapat menyajikan penjelasan yang mendalam dan mudah didengarkan oleh pembaca layar.

Bagian 3 — Logika Cerdas: Menemukan Kata di Dalam Kalimat

Bagaimana cara chatbot mencari kata di antara kalimat panjang pengguna? Kita buat fungsi pintar pencari kata: 

def cari_kata_kunci(kalimat_pengguna, data_kamus):
    # Bersihkan tanda baca umum
    tanda_baca = ["?", "!", ".", ",", ":", ";", '"', "'"]
    kalimat_bersih = kalimat_pengguna.lower()
    for tanda in tanda_baca:
        kalimat_bersih = kalimat_bersih.replace(tanda, "")
    
    # Pecah kalimat menjadi daftar kata
    daftar_kata = kalimat_bersih.split()
    
    # Periksa apakah ada kata yang cocok dengan kamus
    for kata in daftar_kata:
        if kata in data_kamus:
            return kata # Kata ditemukan!
            
    return None # Tidak ada kata yang cocok

Mari perhatikan alur kerjanya: jika pengguna mengetik "Tolong jelaskan arti kata beautiful dong!", fungsi akan membersihkan tanda seru, memecah kalimat menjadi kumpulan kata, dan ketika menemukan kata "beautiful", fungsi langsung mengembalikannya. Sangat praktis dan cerdas!

Bagian 4 — Menambahkan Fitur Ramah: Pengenalan Maksud (Intent Recognition)

Pengguna sering kali tidak langsung bertanya arti kata. Terkadang mereka menyapa terlebih dahulu seperti "halo", "selamat pagi", atau "siapa namamu?".

Dalam AI Chatbot, kemampuan mengenali tujuan pesan ini disebut Intent Recognition. Kita dapat menambahkannya dengan aturan sederhana di dalam program kita: 

# Deteksi salam (Greeting Intent)
salam_list = ["halo", "hai", "selamat pagi", "selamat siang", "assalamualaikum"]
apakah_salam = any(salam in pesan.lower() for salam in salam_list)

if apakah_salam:
    print("Chatbot: Halo! Senang bisa menyapa Anda. Ada kata bahasa Inggris yang ingin Anda ketahui artinya?")
    continue

Dengan menambahkan baris ini sebelum pemindaian kata, chatbot menjadi jauh lebih hangat dan manusiawi saat diajak berinteraksi.

Bagian 5 — Menuju AI Modern: Integrasi Model Bahasa (LLM API)

Lalu, apa yang terjadi jika pengguna menanyakan kata yang belum ada di kamus lokal kita?

Di sinilah peran nyata AI Generatif (Large Language Models / LLM) seperti Google Gemini atau OpenAI:

  1. Pemeriksaan Cepat (Database Lokal): Program mencari kata di kamus_ai lokal terlebih dahulu. Proses ini instan dan tidak memakan kuota internet.
  2. Panggilan Model AI (Fallback API): Jika kata tidak ditemukan di kamus lokal, program secara otomatis mengirimkan permintaan (*request*) ke Model AI melalui API.
  3. Penyusunan Prompt Otomatis: Program menyusun prompt otomatis: 
    prompt = f"Berikan arti kata '{kata}', jenis katanya, dan 1 contoh kalimat beserta terjemahan bahasa Indonesianya secara ringkas."
  4. Menjawab Pengguna: AI mengembalikan jawaban dan menampilkannya kepada pengguna.

Pola penggabungan antara data lokal terstruktur dan model AI generatif inilah yang disebut sebagai Hybrid AI Architecture — fondasi utama aplikasi AI modern saat ini!

Langkah 3: Menulis Kode Program Lengkap

# 1. BASIS DATA KAMUS TERSTRUKTUR (NESTED DICTIONARY)
kamus_ai = {

# 2. FUNGSI PEMINDAI KATA KUNCI (NLP SEDERHANA)
def cari_kata_kunci(kalimat_pengguna, data_kamus):
    # Bersihkan tanda baca umum yang sering diketik manusia
    tanda_baca = ["?", "!", ".", ",", ":", ";", '"', "'"]
    kalimat_bersih = kalimat_pengguna.lower()
    
    for tanda in tanda_baca:
        kalimat_bersih = kalimat_bersih.replace(tanda, "")
    
    # Pecah kalimat menjadi potongan kata (tokenisasi)
    daftar_kata = kalimat_bersih.split()
    
    # Periksa apakah ada kata yang terdaftar di dalam kamus
    for kata in daftar_kata:
        if kata in data_kamus:
            return kata # Kata kunci berhasil ditemukan!
            
    return None # Tidak ada kata yang cocok di kamus


# 3. ANTARMUKA UTAMA PROGRAM (MAIN LOOP)

    # Mengambil input dari pengguna

    # Cek apakah pengguna ingin keluar

        break
    
    # Cek jika pengguna tidak mengetik apa-apa
    if pesan.strip() == "":
        print("Chatbot: Anda belum mengetikkan pertanyaan. Silakan coba lagi.\n")
        continue
    
    # Deteksi salam ramah (Intent Recognition Sederhana)
    salam_list = ["halo", "hai", "selamat pagi", "selamat siang", "selamat sore", "assalamualaikum"]

        print("Chatbot: Halo! Senang menyapa Anda. Silakan tanyakan kata bahasa Inggris yang ingin Anda ketahui artinya.\n")
        continue

    # Lakukan pencarian kata kunci di dalam kalimat pengguna
    kata_ditemukan = cari_kata_kunci(pesan, kamus_ai)
    
    if kata_ditemukan:

Langkah 4: Memahami Bagian-Bagian Kode (Sebelum Menjalankan)

Sebelum kita menjalankan program di terminal, mari kita pahami apa yang sebenarnya dilakukan oleh setiap baris kode yang baru saja Anda tulis:

1. Variabel kamus_ai (Basis Data Terstruktur):
Kita menggunakan nested dictionary (kamus di dalam kamus). Kata bahasa Inggris seperti "house" menjadi kunci utama (*main key*). Di dalamnya tersimpan informasi lengkap: arti, tipe kata, contoh kalimat, dan arti_contoh. Struktur ini membuat data rapi dan mudah diambil kapan saja.

2. Fungsi cari_kata_kunci(kalimat_pengguna, data_kamus):
Ini adalah "otak" pemroses bahasa alami (NLP sederhana) kita. Fungsi ini bekerja melalui 3 tahap:

  • Pembersihan Simbol: Daftar tanda_baca = ["?", "!", ".", ",", ...] digunakan bersama perulangan replace() untuk membuang tanda baca agar kata seperti "house?" menjadi "house" bersih.
  • Pemotongan Kalimat: Baris kalimat_bersih.split() memotong kalimat panjang menjadi daftar kata-kata terpisah.
  • Pencocokan Cerdas: Baris for kata in daftar_kata: memindai setiap kata. Jika kata tersebut terdaftar di data_kamus, fungsi langsung mengembalikannya (return kata). Jika tidak ada yang cocok hingga kata terakhir, fungsi mengembalikan nilai kosong (return None).

3. Perulangan while True::
Perulangan tanpa henti (*infinite loop*) ini memastikan program terus berjalan menerima pertanyaan Anda berkali-kali tanpa langsung tertutup setelah satu kali tanya.

4. Pengecekan if pesan == "keluar"::
Memungkinkan Anda menghentikan program kapan saja secara sopan dengan perintah break.

5. Deteksi Salam Ramah (any(...)):
Sebelum mencari ke kamus, program memeriksa apakah Anda hanya sekadar menyapa (seperti "halo" atau "selamat pagi"). Jika terdeteksi salam, chatbot menyapa balik dan perintah continue membuat program langsung melompat kembali ke atas menunggu pertanyaan berikutnya.

6. Menampilkan Hasil:
Jika kata kunci ditemukan, baris info = kamus_ai[kata_ditemukan] mengambil seluruh rincian lalu mencetaknya ke konsol dengan format yang sangat runtut dan nyaman didengarkan oleh pembaca layar.

Bagian 9 — Fitur Tambahan (Opsional): Membuat Chatbot Mengeluarkan Suara

Bagi peserta yang ingin chatbot tidak hanya mencetak teks di layar, tetapi juga bersuara langsung membacakan hasil terjemahan ke telinga, kita bisa mengintegrasikan library gratis pyttsx3:

1. Instalasi Library di Terminal:

pip install pyttsx3

2. Contoh Koding Suara Sederhana:

import pyttsx3

# Inisialisasi engine suara
engine = pyttsx3.init()
engine.setProperty('rate', 160) # Mengatur kecepatan bicara yang nyaman

def bicara(teks):
    print("Chatbot:", teks)
    engine.say(teks)
    engine.runAndWait()

# Menguji suara:
bicara("Halo, saya asisten kamus cerdas Anda. Ada kata yang ingin dicari?")

Fitur ini membuat chatbot Anda resmi menjadi Asisten Suara Kamus Pribadi yang sepenuhnya offline dan mandiri!
