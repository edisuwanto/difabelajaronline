INTRODUCTION TO HERMES AGENT

Pada pertemuan ini kita melangkah lebih jauh dari sekadar model bahasa percakapan menuju sistem kecerdasan otonom nyata menggunakan Hermes Agent. Kita akan mengeksplorasi bagaimana agent merencanakan tindakan, memanggil tools sistem file dan terminal, memanfaatkan persistent memory lintas sesi, mengaktifkan skills terarah, serta menerapkan prinsip keamanan human-in-the-loop yang aksesibel bagi pengguna screen reader.

Tujuan Pembelajaran

Setelah mengikuti pertemuan ini, peserta diharapkan mampu:

  1. Memahami apa itu Hermes Agent.
  2. Memahami perbedaan chatbot dan autonomous AI Agent.
  3. Memahami arsitektur dasar Hermes Agent.
  4. Memahami konsep model, tools, memory, dan skills.
  5. Menjalankan Hermes Agent di lingkungan lokal.
  6. Berinteraksi dengan Hermes melalui antarmuka terminal yang aksesibel.
  7. Memahami bagaimana agent merencanakan dan menjalankan tools.
  8. Memahami konsep dan cara kerja persistent memory lintas sesi.
  9. Memahami keamanan, batasan hak akses, dan persetujuan tindakan agent (human-in-the-loop).
  10. Merancang use case Hermes Agent untuk kegiatan nyata sehari-hari dan AI Engineering.

Bagian Kedua — Apa Itu Hermes Agent?

Hermes Agent adalah agen kecerdasan buatan mandiri (autonomous AI Agent) yang dikembangkan oleh Nous Research.

Salah satu karakteristik paling penting dari Hermes Agent adalah kemampuannya menggunakan berbagai tools, mempertahankan memory lintas sesi, memanfaatkan modul skills, dan menyelesaikan pekerjaan kompleks dalam beberapa langkah mandiri (multi-step task execution). Hermes juga dirancang fleksibel dengan dukungan terhadap berbagai provider model AI serta berbagai kanal interaksi.

Definisi Sederhana: Hermes Agent adalah AI yang tidak hanya bisa diajak berbicara atau ditanyai pendapat, melainkan AI yang diberi seperangkat alat (tools) dan memori sehingga mampu menyelesaikan pekerjaan nyata di komputer.

Bagian Ketiga — Analogi Sederhana untuk Pengguna Tunanetra: Asisten Pribadi Multi-Tools

Untuk memudahkan pemahaman peserta — khususnya pengguna screen reader tunanetra — bayangkan Anda memiliki seorang asisten pribadi di meja kerja Anda.

Suatu pagi, Anda memberikan arahan kepada asisten tersebut: 

"Tolong siapkan materi pembelajaran Python untuk sesi besok pagi."

Asisten pribadi tersebut dilengkapi dengan berbagai fasilitas kerja:

Otak (Kemampuan berpikir dan bernalar)
  +
Buku (Sumber referensi dan pengetahuan)
  +
Komputer (Alat untuk membuat file dan menjalankan script)
  +
Kalkulator (Alat untuk menghitung data eksak)
  +
Catatan / Buku Agenda (Memori riwayat preferensi Anda)

Asisten tersebut tidak hanya mengucapkan "Baik, saya mengerti", tetapi secara otonom membagi langkah kerjanya menggunakan alat yang tepat sesuai kebutuhan: 

Mencari informasi relevan
       │
       v

       │
       v
Menulis materi pembelajaran
       │
       v
Menyimpan file materi ke disk

Hermes Agent bekerja dengan prinsip yang persis sama. Model AI bertindak sebagai otak yang menentukan langkah bernalar, sedangkan tools komputer menjadi tangan dan alat bantu yang mengeksekusi pekerjaan secara nyata.

Bagian Keempat — Empat Komponen Kunci: Model, Tools, Memory, dan Skills

Untuk menguasai Hermes Agent, kita harus memahami empat pilar arsitektur utamanya: 

1. Model
2. Tools
3. Memory
4. Skills

1. Model (Otak Bahasa)

Model adalah otak bahasa utama (LLM) yang digunakan agent untuk memahami instruksi alami, merencanakan logika, dan menghasilkan respons. Hermes mendukung berbagai model dan provider (baik model lokal open-weights maupun cloud API), sehingga pengguna tidak terkunci pada satu penyedia layanan tertentu. 

Hermes Agent ───> Model AI (Otak Penalaran)

2. Tools (Kapasitas Tindakan Nyata)

Tools adalah perangkat atau kapabilitas tambahan yang diberikan kepada agent agar dapat berinteraksi dengan lingkungan luar. Contoh tools bawaan meliputi:

  • Terminal / Bash: Menjalankan perintah command line di sistem operasi.
  • File System: Membaca, membuat, mengedit, dan mengorganisasi file atau folder.
  • Web & Browser: Mengakses dokumentasi online atau halaman web.
  • Code Execution: Menjalankan script Python untuk kalkulasi atau pengolahan data.
  • Search Engine: Mencari informasi terbaru secara online.

3. Memory (Penyimpanan Konteks Lintas Sesi)

Memory memungkinkan agent mengingat informasi penting, preferensi pengguna, dan riwayat tugas sebelumnya meskipun terminal ditutup dan dibuka kembali pada hari berikutnya. Hermes Agent dilengkapi sistem persistent memory lintas sesi sehingga pekerjaan jangka panjang dapat diteruskan tanpa kehilangan konteks.

4. Skills (Prosedur Keahlian Khusus)

Skill adalah serangkaian instruksi kerja atau prosedur terstandarisasi yang dapat dipanggil agent untuk menyelesaikan domain tugas tertentu secara rapi, seperti analisis dataset CSV, audit keamanan kode, pembuatan dokumen laporan, atau perancangan arsitektur database.

Formula Autonomous AI Agent:
Model + Tools + Memory + Skills = Autonomous AI Agent yang Andal

Bagian Kelima — Hermes Bukan Sekadar Chatbot: Task Execution Nyata

Mari kita cermati perbedaan nyata perilaku chatbot biasa dengan Hermes Agent saat dihadapkan pada tugas yang sama:

Skenario Chatbot Konvensional

Pengguna : "Apa itu Python?"
AI       : "Python adalah bahasa pemrograman tingkat tinggi..."
(Selesai — tidak ada tindakan apa pun pada komputer Anda)

Skenario Hermes Agent (Task Execution)

Pengguna : "Analisis file data ini dan buatkan ringkasannya dalam bentuk file baru."

Hermes Agent mengeksekusi tahapan:
1. Membuka folder dan menemukan file target.
2. Membaca isi file data tersebut menggunakan File Tool.
3. Menjalankan analisis dan kalkulasi data.
4. Menulis file baru ringkasan_data.txt ke direktori kerja.
5. Memeriksa kembali isi file dan melaporkan hasil kepada pengguna.

Dengan demikian, perbedaan intinya terletak pada Task Execution: agent dapat mengubah ide dan tujuan menjadi rangkaian tindakan nyata yang selesai dikerjakan.

Bagian Keenam — Panduan Instalasi Menggunakan Command Prompt (CMD) untuk Pengguna Screen Reader

Hermes Agent memiliki keunggulan aksesibilitas tinggi karena seluruh operasinya berjalan di antarmuka berbasis teks. Bagi tunanetra pengguna pembaca layar (seperti NVDA atau JAWS), Command Prompt (CMD) adalah lingkungan konsol yang paling ringan, stabil, dan ramah dengan screen reader di sistem operasi Windows karena output teksnya linier dan tidak terganggu oleh formatting grafis yang rumit.

Berikut adalah panduan instalasi resmi langkah demi langkah khusus menggunakan Command Prompt (CMD) saja yang ramah screen reader:

Langkah 1: Membuka Command Prompt (CMD) di Windows

  1. Tekan kombinasi tombol Windows + R pada keyboard untuk membuka kotak dialog Run.
  2. Ketikkan teks cmd lalu tekan tombol Enter.
  3. Dengarkan umpan balik suara dari screen reader Anda. Screen reader akan membacakan judul jendela dan prompt aktif, misalnya: C:\Users\NamaAnda>. Ini menandakan terminal Command Prompt telah aktif dan siap menerima perintah.

Langkah 2: Menjalankan Perintah Instalasi Hermes Agent Langsung dari CMD

Nous Research menyediakan script installer terpadu. Kita dapat mengeksekusinya langsung dari dalam Command Prompt (CMD) menggunakan satu baris perintah otomatis dengan parameter -ExecutionPolicy Bypass, sehingga Anda tidak perlu membuka PowerShell terpisah dan tidak perlu mengubah kebijakan keamanan sistem secara manual: 

powershell -ExecutionPolicy Bypass -Command "iex (irm https://hermes-agent.nousresearch.com/install.ps1)"

Panduan Keyboard Pengguna Screen Reader:

  1. Salin perintah di atas ke clipboard dengan menekan tombol Ctrl + C.
  2. Pindah kembali ke jendela Command Prompt dengan menekan Alt + Tab.
  3. Tempelkan perintah ke CMD dengan menekan Ctrl + V (pada Windows 10/11) atau tekan Alt + Spasi, tekan tombol panah bawah ke menu Edit, lalu tekan Paste.
  4. Tekan tombol Enter untuk memulai proses unduh dan instalasi otomatis.

Catatan: Installer ini akan otomatis menyiapkan runtime Python portabel mandiri (melalui uv), dependensi internal, dan binary command Hermes di folder lokal pengguna tanpa merusak konfigurasi Python yang sudah ada sebelumnya di komputer Anda.

Langkah 3: Memantau Proses Instalasi dengan Screen Reader di CMD

Proses instalasi membutuhkan waktu sekitar 3 hingga 10 menit tergantung kecepatan koneksi internet Anda. Selama proses berjalan, teks log instalasi akan terus bertambah di layar terminal.

  • Pengguna NVDA:
    • Tekan tombol NVDA + Panah Atas untuk membacakan baris teks yang baru saja muncul di terminal CMD.
    • Gunakan Review Cursor Numpad (pastikan tombol NumLock dalam keadaan mati): tekan Numpad 7 untuk membaca baris atas, Numpad 8 untuk membaca baris saat ini, dan Numpad 9 untuk membaca baris bawah.
    • Tekan NVDA + B jika ingin screen reader membacakan seluruh teks jendela terminal dari atas ke bawah.
  • Pengguna JAWS:
    • Tekan tombol Insert + Panah Atas untuk membacakan baris teks aktif saat ini.
    • Aktifkan JAWS Cursor dengan menekan tombol Minus di Numpad, lalu gunakan Panah Atas dan Panah Bawah untuk menelusuri riwayat teks instalasi baris demi baris. Tekan Plus di Numpad untuk kembali ke kursor PC normal.

Tanda Instalasi Selesai: Terminal CMD berhenti mengalirkan teks baru dan prompt perintah kembali muncul di baris paling akhir, misalnya: C:\Users\NamaAnda>.

Langkah 4: Menutup dan Membuka Kembali Command Prompt (Refresh PATH)

Setelah instalasi selesai, installer telah menambahkan path program Hermes ke variabel lingkungan sistem. Agar Command Prompt dapat langsung mengenali perintah hermes, Anda perlu menyegarkan terminal dengan cara menutup dan membukanya kembali:

  1. Ketikkan perintah exit pada jendela CMD lalu tekan Enter untuk menutup jendela tersebut.
  2. Tekan tombol Windows + R, ketikkan cmd, lalu tekan Enter untuk membuka jendela Command Prompt yang baru.

Langkah 5: Memverifikasi Keberhasilan Instalasi di CMD

Di jendela Command Prompt yang baru terbuka, ketikkan perintah verifikasi berikut lalu tekan Enter: 

hermes --version

Screen reader Anda akan membacakan nomor versi Hermes yang terpasang (misalnya: hermes 0.x.x). Jika pembaca layar membacakan nomor versi tersebut tanpa pesan kesalahan, selamat! Hermes Agent telah berhasil terinstal 100% menggunakan CMD dan siap digunakan.

Bagian Ketujuh — Panduan Setting Awal dan Konfigurasi Penggunaan Hermes Agent

Setelah proses instalasi berhasil, langkah berikutnya adalah melakukan Setting Awal (Initial Configuration) sebelum menggunakan agent untuk bekerja.

Tahap 1: Mempersiapkan Direktori Kerja Proyek

Sangat disarankan untuk selalu menjalankan agent di dalam folder khusus proyek AI Anda agar file yang dibuat atau dianalisis terorganisasi rapi. Di jendela terminal, ketikkan: 

mkdir proyek_hermes
cd proyek_hermes

Perintah ini membuat folder baru bernama proyek_hermes dan memindahkan posisi terminal Anda ke dalam folder tersebut.

Tahap 2: Menjalankan Hermes untuk Pertama Kali (Setup Wizard)

Ketikkan perintah utama di terminal lalu tekan Enter: 

hermes

Pada peluncuran pertama kali, Hermes akan mendeteksi bahwa konfigurasi model belum ada, dan akan secara otomatis membuka Setup Wizard interaktif langsung di terminal.

Tahap 3: Memilih Provider Model dan Memasukkan API Key

  1. Memilih Provider AI: Terminal akan menampilkan daftar pilihan model (seperti Nous Portal, OpenRouter, Anthropic, OpenAI, atau Model Lokal Ollama). Navigasi pilihan menggunakan Panah Bawah atau Panah Atas, lalu tekan Enter pada opsi yang Anda gunakan. Screen reader akan membacakan opsi yang sedang disorot.
  2. Memasukkan API Key: Wizard akan menampilkan prompt input bertuliskan Enter your API Key:. Salin API key Anda dari browser/catatan, kembali ke terminal, tekan Ctrl + V untuk menempelkan, lalu tekan Enter. (Demi alasan keamanan, karakter kunci mungkin tidak dibacakan satu per satu oleh screen reader).
  3. Memilih Model Default: Pilih model penalaran utama yang diinginkan (misalnya Hermes 3 atau model kompatibel lainnya), lalu tekan Enter.

Tahap 4: Mengatur Kebijakan Persetujuan Keamanan (Safety Approval Profile)

Hermes Agent akan menanyakan preferensi konfirmasi saat menjalankan tools (seperti perintah terminal atau pembuatan file).

Rekomendasi untuk Pemula: Pilih mode "Ask for Approval" (Minta Persetujuan). Dengan pengaturan ini, setiap kali agent hendak mengeksekusi perintah shell atau mengubah file di komputer, terminal akan membunyikan prompt konfirmasi berupa pertanyaan: Execute tool [nama_tool]? (y/n). Pengguna cukup menekan tombol y lalu Enter untuk mengizinkan, atau n lalu Enter untuk menolak. Hal ini menjamin kendali penuh selalu berada di tangan Anda!

Tahap 5: Perintah Dasar dan Navigasi Sesi

Setelah setup awal selesai, prompt interaktif Hermes siap menerima instruksi Anda. Beberapa perintah navigasi penting yang perlu dihafal:

  • /help — Menampilkan panduan bantuan dan daftar perintah internal.
  • /clear — Membersihkan tampilan layar terminal (sangat membantu jika screen reader terasa lambat karena riwayat teks terlalu panjang).
  • /exit atau tombol Ctrl + C — Keluar dari sesi interaktif Hermes dan kembali ke prompt Command Prompt (CMD) standar.

Bagian Kedelapan — Memberikan Tugas kepada Agent: Dari Teks Menuju Tindakan

Sekarang kita akan menguji kapabilitas sejati Hermes sebagai agen otonom dengan memberikan perintah yang membutuhkan aksi nyata ke sistem file: 

Instruksi Pengguna:
"Buat sebuah file bernama catatan_python.txt yang berisi tiga konsep dasar Python:
variabel, fungsi, dan perulangan. Jelaskan masing-masing secara ringkas."

Jika konfigurasi tools mengizinkan akses file, Hermes tidak sekadar mencetak teks penjelasan di terminal. Hermes akan menjalankan alur kerja internal: 

Instruksi Pengguna
       │
       v
Hermes Agent
       │
       v
Memahami tujuan instruksi
       │
       v
Memilih tool (File Creation Tool)
       │
       v
Menjalankan tindakan menulis ke file catatan_python.txt
       │
       v

       │
       v

Inilah pembeda fundamental antara Generate Text (hanya mengetik jawaban) dan Execute Task (menyelesaikan pekerjaan secara nyata di sistem).

Bagian Kesembilan — Konsep dan Mekanisme Tool Calling

Pada Pertemuan 6 kita telah membahas teori di balik Tool Calling. Pada Hermes Agent, kita melihat implementasinya bekerja secara otomatis di depan mata kita.

Misalnya kita meminta instruksi investigasi:

"Hitung jumlah file Python yang ada di dalam folder proyek ini dan sebutkan nama-namanya."

Tanpa kemampuan tools, sebuah chatbot hanya bisa menerka-nerka atau meminta pengguna untuk menjalankan perintah dir sendiri. Tetapi Hermes Agent menjalankan alur berikut: 

Pengguna
   │
   v
Hermes Agent
   │
   ├── [Perlu informasi isi folder lokal]
   │
   v
Tool File System / Terminal (dir atau ls *.py)
   │
   v
Hasil output nyata dari sistem operasi
   │
   v
Hermes Agent (Menganalisis daftar file yang didapat)
   │
   v
Jawaban akurat berdasarkan fakta sistem

Agent tidak perlu menebak (hallucinate). Ia memanggil tool yang relevan untuk memperoleh informasi faktual secara real-time.

Bagian Kesepuluh — Multi-Step Reasoning dan Task Decomposition

Ciri khas utama sistem cerdas otonom adalah Multi-Step Reasoning yang didukung oleh konsep Task Decomposition (pemecahan tugas).

Ketika kita memberikan satu instruksi besar, misalnya: 

"Buatkan ringkasan komprehensif mengenai proyek Python saya."

Hermes secara mandiri menguraikan instruksi tersebut menjadi serangkaian subtugas teratur: 

Langkah 1: Menelusuri seluruh file dalam direktori proyek.
Langkah 2: Membaca file konfigurasi dan file utama (seperti README.md, main.py).
Langkah 3: Mengidentifikasi dependensi, arsitektur modul, dan struktur kode.
Langkah 4: Mensintesis temuan menjadi dokumen ringkasan yang terstruktur.
Langkah 5: Menyajikan laporan kepada pengguna atau menyimpannya dalam berkas ringkasan.

Konsep Kunci: Task Decomposition adalah prinsip di mana sebuah masalah besar dipecah menjadi langkah-langkah atomik yang dapat dieksekusi satu per satu dengan validasi hasil di setiap tahap.

Bagian Kesebelas — Persistent Memory: Menjaga Konteks Lintas Sesi

Model bahasa biasa bersifat stateless (lupa segera setelah sesi chat berakhir). Namun Hermes Agent mendukung sistem Persistent Memory.

Bayangkan percakapan kita hari ini:

Hari ini:
Pengguna : "Saya sedang mengembangkan aplikasi asistif AI untuk teman-teman tunanetra bernama Difabelajar."
Hermes   : "Dipahami, konteks proyek Difabelajar telah disimpan ke memori."

Keesokan harinya, terminal ditutup lalu dibuka kembali di komputer yang sama:

Keesokan harinya:
Pengguna : "Lanjutkan perancangan modul aplikasi saya kemarin."

Dengan persistent memory, agent langsung mengenali bahwa aplikasi yang dimaksud adalah Difabelajar untuk asistif tunanetra, modul apa saja yang sudah dibahas, serta pendekatan teknis yang disepakati sebelumnya. 

Sesi 1 (Penyampaian Informasi & Proyek)
      │
      v
Persistent Memory Store (Tersimpan di Disk)
      │
      v
Sesi 2 (Hari Berikutnya — Pemanggilan Konteks)
      │
      v
Sesi Lanjutan Berkesinambungan

Bagian Kedua Belas — Skills: Memberikan Prosedur Khusus kepada Agent

Fitur unggulan lainnya dalam Hermes adalah Skills. Skill adalah modul prosedur khusus yang memberi tahu agent cara baku menyelesaikan tugas tertentu dengan standar operasional yang baku.

Contoh skenario skill:

Skill: Analisis Data CSV Peserta
Input   : File nilai_peserta.csv
Proses  : Hitung rata-rata, nilai tertinggi, dan sebaran kompetensi
Output  : Laporan tabel analitik dan rekomendasi belajar

Dengan konsep modular ini, kita dapat membayangkan Hermes Agent sebagai pusat komando yang dipersenjatai dengan ragam skill:

Hermes Agent
   │
   ├─── Skill Analisis Data
   │
   ├─── Skill Pembuatan Laporan
   │
   ├─── Skill Python & Code Review
   │
   └─── Skill Web Research & Verifikasi Sumber

Ketika sebuah skill diaktifkan, agent mengikuti pedoman terstruktur sehingga hasil pekerjaan konsisten dan tidak melenceng.

Bagian Keempat Belas — Keamanan AI Agent dan Human-in-the-Loop

Bagian ini adalah salah satu materi paling krusial bagi calon AI Engineer. Karena AI Agent memiliki akses ke sistem nyata komputer, potensi bahayanya jauh lebih besar daripada chatbot biasa jika tidak dikendalikan dengan benar. 

Potensi Risiko jika Tanpa Batasan:
AI + Akses Terminal Bebas + Akses File Penuh + Akses Internet Bebas
(Bila terjadi kesalahan atau prompt injection, file penting bisa terhapus!)

Untuk memastikan keselamatan sistem, arsitektur AI Agent menerapkan lima pilar pengamanan:

  1. Permission (Izin): Agent hanya dapat mengakses direktori dan tool yang diizinkan secara eksplisit.
  2. Approval (Persetujuan): Untuk tindakan berisiko (seperti menghapus file atau mengeksekusi shell script), sistem meminta konfirmasi manual pengguna terlebih dahulu.
  3. Sandbox (Isolasi): Perintah dieksekusi dalam lingkungan virtual atau container terbatas.
  4. Logging (Pencatatan): Setiap perintah, argumen tool, dan output tercatat rapi dalam berkas log untuk audit.
  5. Human-in-the-Loop: Manusia tetap memegang kendali tertinggi (otoritas keputusan akhir).

Prinsip Emas Keamanan Agent:
Semakin besar kemampuan tindakan yang dimiliki sebuah agent, semakin ketat dan transparan sistem kontrol keamanan yang wajib diterapkan.

Bagian Kelima Belas — Aksesibilitas Hermes Agent untuk Pengguna Screen Reader

Salah satu daya tarik terbesar Hermes Agent bagi pembelajar tunanetra adalah bahwa antarmuka intinya berbasis Terminal dan Teks Murni (CLI).

Alur interaksi aksesibel:

Keyboard (Input Perintah Bersih)
   │
   v
Terminal (Command Prompt / CMD)
   │
   v
Hermes Agent (Memproses & Eksekusi)
   │
   v
Teks Output Terstruktur
   │
   v
Screen Reader (NVDA / JAWS / Orca membacakan setiap baris secara akurat)

Banyak antarmuka AI berbasis grafis modern (GUI) memiliki tombol tanpa label (unlabeled buttons), kanvas visual yang tidak terbaca screen reader, atau animasi yang membingungkan. Sebaliknya, antarmuka terminal memberikan kendali navigasi penuh dengan tombol panah, review cursor, serta pembacaan baris demi baris yang sangat efisien dan mandiri bagi tunanetra.

Bagian Keenam Belas — Panduan Praktik Terbimbing di Kelas

Dalam sesi praktik di kelas, hindari langsung memberikan tugas yang berisiko tinggi seperti mengubah atau menghapus berkas sistem. Terapkan prinsip Read-Only First:

Praktik 1: Eksplorasi Aman (Read-Only)

"Jelaskan struktur folder proyek Python saya saat ini tanpa mengubah file apa pun."

Perhatikan bagaimana agent memanggil tool pembaca direktori dan memetakan struktur file tanpa menyentuh konten.

Praktik 2: Membaca dan Meringkas Dokumen

"Baca file README.md di folder ini, lalu buatkan ringkasan 3 poin utama tentang tujuan proyek tersebut."

Praktik 3: Audit Kode Pasif

"Periksa file main.py, analisis apakah ada fungsi yang belum memiliki penanganan error, dan jelaskan cara perbaikannya tanpa mengubah file aslinya."

Setelah peserta menguasai pola observasi tindakan agent yang aman, barulah peserta diperkenalkan pada pemberian izin pembuatan file baru di bawah supervisi instruktur.

Bagian Ketujuh Belas — Eksperimen Agent: Perencanaan Sebelum Eksekusi

Sebagai latihan berpikir kritis (agentic thinking), berikan instruksi kepada Hermes yang menguji kemampuan perencanaannya tanpa eksekusi langsung: 

Instruksi Eksperimen:
"Buatkan daftar rencana 5 langkah untuk membangun sebuah aplikasi AI Assistant penerjemah sederhana.
PENTING: Jangan menjalankan perintah sistem atau mengubah file apa pun sekarang!"

Amati bagaimana agent menyusun urutan logika. Setelah agent selesai merespons, tanyakan tindak lanjut: 

"Jelaskan tools apa saja yang kemungkinan akan kamu butuhkan untuk menyelesaikan rencana tersebut secara mandiri?"

Latihan ini melatih peserta untuk membedakan secara tegas antara fase Planning (Perencanaan) dan fase Execution (Eksekusi).

Bagian Kedelapan Belas — Tugas Mandiri: Merancang Arsitektur AI Agent

Buatlah rancangan arsitektur sebuah AI Agent untuk mempermudah kegiatan sehari-hari atau pekerjaan profesional Anda. Pilihlah salah satu tema berikut:

  1. AI Coding Assistant
  2. AI Data Assistant
  3. AI Research Assistant
  4. AI File & Folder Assistant
  5. AI Learning / Study Assistant
  6. AI Business & Office Assistant

Tuliskan rancangan Anda dengan struktur format wajib berikut:

Nama Agent : [Nama unik agen Anda]
Tujuan     : [Sasaran utama yang ingin diselesaikan]
Model      : [Model bahasa yang dipilih, misal: Hermes 3 / Llama 3 / Claude / GPT]
Tools      : [Alat yang dibutuhkan, misal: File, Terminal, Python, Web Search]
Memory     : [Informasi apa yang harus diingat lintas sesi percakapan]
Skills     : [Prosedur khusus yang dikuasai agen]
Tugas      : [Contoh instruksi operasional yang diberikan pengguna]
Output     : [Bentuk hasil akhir yang disajikan kepada pengguna]

Contoh Pengisian yang Baik:

Nama Agent : AI Learning Assistant
Tujuan     : Membantu peserta tunanetra belajar pemrograman Python secara bertahap dan terstruktur.
Model      : Nous Hermes 3 / Llama-3-8B
Tools      : Terminal lokal, File reader/writer, Python REPL runner.
Memory     : Riwayat materi yang sudah dipelajari, catatan kesalahan sintaks yang sering dilakukan peserta, dan preferensi penjelasan suara.
Skills     : Modul penjelasan ramah screen reader, generator latihan soal adaptif, dan pemeriksa kode ramah pemula.
Tugas      : Membaca kode latihan peserta, mendeteksi baris eror, lalu membuatkan latihan perbaikan bertahap.
Output     : Penjelasan naratif yang mudah dibaca screen reader dan berkas kode perbaikan yang bersih dari error.

Dengan demikian, perjalanan kursus Anda akan diakhiri bukan sekadar dengan wawasan konsep, melainkan dengan karya aplikasi AI konkret yang siap digunakan dan dibanggakan!
