Learning Python for AI Engineering
Mengubah Instruksi Menjadi Program yang Dapat Bekerja

Setelah mempelajari materi ini, peserta mampu:

  • Memahami peran Python dalam AI Engineering.
  • Memahami konsep dasar program Python.
  • Menggunakan variabel untuk menyimpan informasi.
  • Menerima input dari pengguna menggunakan input().
  • Memahami konsep Input, Process, Output.
  • Menggunakan percabangan dengan if dan else.
  • Menggunakan perulangan dalam program Python.
  • Membuat dan menggunakan function.
  • Mengenal library Python dan penggunaannya dalam AI Engineering.
  • Memahami penggunaan JSON untuk pertukaran data.
  • Membuat program chat sederhana menggunakan Python.

Bagian 1 — Mengapa AI Engineer Perlu Python?

Pada pertemuan sebelumnya kita sudah memahami bahwa AI Engineer tidak hanya menggunakan AI, tetapi juga menghubungkan AI dengan aplikasi.

Di sinilah Python berperan.

Bayangkan model AI sebagai seorang ahli yang sangat pintar. Namun, ahli tersebut tidak dapat langsung berinteraksi dengan pengguna aplikasi kita. Kita membutuhkan seseorang yang mengatur komunikasi antara pengguna dan ahli tersebut.

Dalam analogi ini, Python bertindak seperti penghubung antara pengguna, aplikasi, data, dan model AI.

Contohnya:

Pengguna
↓
Aplikasi Python
↓
Model AI
↓
Aplikasi Python
↓
Pengguna

Python dapat digunakan untuk menerima pertanyaan pengguna, mengolah data, mengirim permintaan ke AI, menerima jawaban, kemudian menampilkan hasilnya.

Karena itu, kita tidak perlu mempelajari seluruh bahasa Python terlebih dahulu. Kita fokus pada bagian yang paling sering digunakan dalam AI Engineering.

Bagian 2 — Konsep Dasar Program Python

Sebuah program pada dasarnya berisi instruksi. Komputer akan menjalankan instruksi tersebut untuk menghasilkan suatu tindakan atau hasil.

Contoh program Python paling sederhana:

print("Halo AI Engineering")

Perintah print() digunakan untuk menampilkan informasi.

Jika program dijalankan, hasilnya:

Halo AI Engineering

Perhatikan bahwa komputer menjalankan instruksi yang kita berikan. Ini merupakan konsep penting dalam programming.

Program adalah kumpulan instruksi yang dijalankan komputer untuk menghasilkan suatu tindakan atau hasil.

Bagian 3 — Variabel

Variabel dapat dibayangkan sebagai tempat penyimpanan informasi.

Misalnya kita ingin menyimpan nama peserta. 

nama = "Edi"

Sekarang variabel nama berisi teks: 

Edi

Kita dapat menampilkannya:

nama = "Edi"

print(nama)

Hasil:

Edi

Kita juga dapat menyimpan angka. 

umur = 25

print(umur)

Dalam AI Engineering, variabel sangat penting karena program akan terus menerima dan menyimpan informasi.

Misalnya:

pertanyaan = "Apa itu AI?"

Variabel pertanyaan sekarang menyimpan pertanyaan pengguna.

Bagian 4 — Input dari Pengguna

Aplikasi AI harus bisa menerima informasi dari pengguna. Python menyediakan fungsi input().

Contoh:

nama = input("Masukkan nama Anda: ")

print("Halo", nama)

Ketika program dijalankan:

Masukkan nama Anda:

Pengguna dapat mengetik:

Edi

Kemudian program menghasilkan:

Halo Edi

Konsep ini sangat penting untuk chatbot.

Misalnya:

pertanyaan = input("Apa pertanyaan Anda? ")

print("Anda bertanya:", pertanyaan)

Nantinya bagian print() dapat digantikan dengan proses untuk mengirim pertanyaan ke model AI.

Bagian 5 — Input, Process, Output

Sekarang kita gabungkan konsep yang sudah dipelajari. Sebuah program sederhana memiliki pola:

Input
↓
Process
↓
Output

Contohnya:

nama = input("Nama: ")

pesan = "Halo " + nama

print(pesan)

Jika pengguna memasukkan:

Edi

Maka program melakukan:

Input:

Edi

Process:

"Halo " + "Edi"

Output:

Halo Edi

Konsep Input → Process → Output akan terus digunakan ketika kita membuat sistem AI.

Bagian 6 — Percabangan dengan If

Dalam AI Engineering, program sering harus mengambil keputusan.

Misalnya kita ingin membuat program yang menentukan apakah seseorang sudah boleh mengikuti kelas. 

umur = int(input("Masukkan umur: "))

if umur >= 17:
    print("Anda dapat mengikuti kelas.")
else:
    print("Anda belum memenuhi syarat.")

Jika umur yang dimasukkan adalah: 

20

Hasilnya:

Anda dapat mengikuti kelas.

Python memeriksa kondisi: 

umur >= 17

Jika benar, program menjalankan bagian if. Jika salah, program menjalankan bagian else.

Konsep ini akan berguna ketika AI harus mengambil keputusan berdasarkan kondisi tertentu.

Bagian 7 — Perulangan

Perulangan digunakan ketika kita ingin menjalankan instruksi berkali-kali.

Contohnya:

for i in range(5):
    print("Belajar AI Engineering")

Hasilnya:

Belajar AI Engineering
Belajar AI Engineering
Belajar AI Engineering
Belajar AI Engineering
Belajar AI Engineering

Dalam aplikasi AI, perulangan dapat digunakan misalnya untuk:

  • Membaca banyak data.
  • Memproses banyak pertanyaan.
  • Membaca daftar kata.
  • Melakukan proses terhadap banyak dokumen.

Bagian 8 — Function

Function adalah sekumpulan instruksi yang kita beri nama sehingga dapat digunakan kembali.

Contoh:

def sapa():
    print("Selamat datang di AI Engineering")

Untuk menjalankannya:

sapa()

Hasil:

Selamat datang di AI Engineering

Function menjadi penting ketika program mulai besar.

Misalnya kita membuat function untuk memproses pertanyaan: 

def proses_pertanyaan(pertanyaan):
    print("Pertanyaan:", pertanyaan)
    print("Sedang diproses...")

Kemudian:

proses_pertanyaan("Apa itu AI?")

Hasil:

Pertanyaan: Apa itu AI?
Sedang diproses...

Nantinya function seperti ini dapat dikembangkan menjadi function yang benar-benar memanggil model AI.

Bagian 9 — Library Python

Python memiliki banyak library yang membantu programmer melakukan pekerjaan tertentu.

Kita tidak harus membuat semuanya dari awal.

Contohnya, library math dapat digunakan untuk operasi matematika. 

import math

hasil = math.sqrt(25)

print(hasil)

Hasil:

5.0

import berarti kita meminta Python menggunakan library tertentu.

Dalam AI Engineering nanti kita akan menemukan library untuk:

  • Pengolahan data.
  • HTTP request.
  • JSON.
  • Machine Learning.
  • Deep Learning.
  • AI API.
  • Database.

Salah satu library yang akan sangat berguna adalah requests.

Contohnya:

import requests

Library tersebut dapat digunakan untuk melakukan komunikasi HTTP dengan sebuah API.

Konsep API akan kita bahas lebih lanjut pada materi AI dan pengembangan aplikasi berikutnya.

Bagian 10 — Python dan JSON

AI Engineering sangat sering berhubungan dengan data dalam format JSON.

JSON merupakan format data yang umum digunakan untuk pertukaran informasi antar aplikasi.

Contohnya:

{
    "nama": "Edi",
    "keahlian": "AI Engineering"
}

Python dapat membaca dan mengolah JSON menggunakan library bawaan: 

import json

data = {
    "nama": "Edi",
    "keahlian": "AI Engineering"
}

teks = json.dumps(data)

print(teks)

JSON penting karena banyak API AI mengirimkan dan menerima data dalam format tersebut.

Dengan kata lain:

Python
↓
JSON
↓
API
↓
AI Model

Konsep ini akan menjadi dasar untuk materi berikutnya.

Bagian 11 — Membuat Program Chat Sederhana

Sekarang kita gabungkan beberapa konsep yang telah dipelajari.

Buat file:

chat.py

Isi dengan kode berikut:

nama = input("Nama Anda: ")

print("Halo", nama)

print("Selamat datang di program AI sederhana.")

while True:

    pertanyaan = input("Anda: ")

    if pertanyaan.lower() == "keluar":
        print("Program selesai.")
        break

    print("Sistem menerima:", pertanyaan)

Jalankan dengan perintah:

python chat.py

Contoh penggunaan:

Nama Anda: Edi

Halo Edi

Selamat datang di program AI sederhana.

Anda: Apa itu AI?

Sistem menerima: Apa itu AI?

Anda: Apa itu Python?

Sistem menerima: Apa itu Python?

Anda: keluar

Program selesai.

Perhatikan bahwa program tersebut sudah memiliki bentuk dasar chatbot.

Tetapi ada satu hal yang belum ada:

AI Model.

Saat ini program hanya mengulangi pertanyaan pengguna.

Pada pertemuan-pertemuan berikutnya, kita akan mengganti bagian tersebut dengan proses AI yang sebenarnya.
