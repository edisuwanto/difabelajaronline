Dasar Prompting — Cara Memberi Instruksi ke AI
Modul Topik 5 — Artificial Intelligence Fundamental

Tujuan Pembelajaran

Setelah mempelajari modul ini, peserta mampu:

  • Memahami apa itu prompt dan mengapa penting
  • Menyusun prompt yang jelas, terstruktur, dan efektif
  • Menggunakan teknik prompting dasar (Role, Task, Context, Output)
  • Menghindari kesalahan umum dalam memberi instruksi ke AI
  • Menggunakan AI untuk menulis, merangkum, menjelaskan, dan membuat ide
  • Menggunakan contoh analogi yang mudah dipahami pengguna screen reader

Bagian 1 — Apa Itu Prompt?

1. Definisi Sederhana

Prompt adalah instruksi atau perintah yang Anda berikan kepada AI.

Prompt bisa berupa:

  • Pertanyaan
  • Perintah
  • Deskripsi
  • Konteks
  • Contoh

Menurut Google AI Essentials, prompt adalah cara kita berkomunikasi dengan AI untuk mendapatkan hasil yang kita inginkan.

Menurut Microsoft Learn AI, prompt adalah instruksi yang menentukan bagaimana AI merespons.

2. Mengapa Prompt Penting?

AI tidak bisa membaca pikiran. AI hanya bisa bekerja berdasarkan instruksi yang Anda berikan.

Prompt yang baik menghasilkan:

  • Jawaban lebih akurat
  • Jawaban lebih sesuai kebutuhan
  • Jawaban lebih terstruktur
  • Jawaban lebih mudah dipahami

Prompt yang buruk menghasilkan:

  • Jawaban tidak sesuai
  • Jawaban terlalu umum
  • Jawaban tidak lengkap

Analogi untuk pengguna screen reader:
Prompt itu seperti memberi instruksi kepada siswa. Jika instruksinya jelas, siswa mengerjakan dengan benar. Jika instruksinya kabur, siswa bingung dan hasilnya tidak sesuai.

Bagian 2 — Struktur Prompt yang Baik (Role, Task, Context, Output)

Ini adalah struktur prompting yang diajarkan oleh:

  • OpenAI Prompt Engineering Guide
  • DeepLearning.AI Prompt Engineering Course
  • Microsoft Prompting Framework

Struktur ini sangat mudah dipahami oleh pemula.

1. Role (Peran AI)

Anda memberi tahu AI harus berperan sebagai siapa.

Contoh:

  • “Bertindak sebagai guru bahasa Indonesia.”
  • “Bertindak sebagai penjelas konsep untuk tunanetra.”
  • “Bertindak sebagai penulis profesional.”

Mengapa penting?
Karena AI akan menyesuaikan gaya bahasa, kedalaman materi, dan cara menjelaskan.

2. Task (Tugas yang Diminta)

Ini adalah apa yang harus AI lakukan.

Contoh:

  • “Jelaskan.”
  • “Ringkas.”
  • “Buatkan.”
  • “Perbaiki.”
  • “Susun.”

3. Context (Konteks Tambahan)

Ini adalah informasi pendukung agar AI memahami situasi.

Contoh:

  • “Untuk siswa tunanetra.”
  • “Gunakan bahasa sederhana.”
  • “Untuk postingan Instagram.”
  • “Untuk laporan sekolah.”

Semakin lengkap konteksnya, semakin baik hasilnya.

4. Output (Format Hasil yang Diinginkan)

Anda menentukan bentuk hasilnya.

Contoh:

  • “Buat dalam 3 paragraf.”
  • “Gunakan poin-poin.”
  • “Gunakan bahasa formal.”
  • “Gunakan analogi audio.”

Bagian 3 — Contoh Prompt Dasar yang Efektif

Contoh 1 — Menulis Email

Prompt buruk:
“Tolong buat email.”

Prompt baik:
“Bertindak sebagai penulis profesional.
Tugas: buat email permohonan izin tidak masuk kerja.
Konteks: saya sedang sakit flu.
Output: 1 paragraf, bahasa formal.”

Contoh 2 — Merangkum Teks

Prompt buruk:
“Ringkas ini.”

Prompt baik:
“Ringkas teks berikut menjadi 5 poin utama.
Gunakan bahasa sederhana.
Output ramah screen reader.”

Contoh 3 — Menjelaskan Konsep

Prompt buruk:
“Jelaskan AI.”

Prompt baik:
“Jelaskan apa itu AI untuk pemula.
Gunakan analogi audio.
Jelaskan dalam 3 paragraf pendek.”

Bagian 4 — Teknik Prompting Dasar (Dari Sumber Terpercaya)

Teknik ini berasal dari:

  • Google AI Essentials
  • Microsoft Prompting Guide
  • OpenAI Best Practices

1. Teknik “Berikan Contoh” (Few-Shot Prompting)

Anda memberi contoh agar AI meniru gaya tersebut.

Contoh:
“Berikan penjelasan seperti contoh berikut:
Contoh: ‘AI adalah teknologi yang membantu komputer belajar dari data.’
Sekarang jelaskan Machine Learning.”

2. Teknik “Perbaiki Jawaban” (Refinement Prompting)

Anda bisa meminta AI memperbaiki jawabannya.

Contoh:
“Perbaiki jawaban sebelumnya agar lebih singkat dan mudah dipahami.”

3. Teknik “Langkah demi Langkah” (Chain-of-Thought)

AI diminta menjelaskan proses berpikirnya.

Contoh:
“Jelaskan langkah demi langkah bagaimana AI mengenali suara.”

4. Teknik “Batasi Output”

Agar jawaban tidak terlalu panjang.

Contoh:
“Jelaskan dalam 5 kalimat saja.”

Bagian 5 — Kesalahan Umum dalam Prompting

  1. Prompt terlalu pendek
    Contoh: “Jelaskan.”
    Hasilnya tidak jelas.
  2. Tidak memberi konteks
    Contoh: “Buat cerita.”
    Cerita bisa tidak sesuai kebutuhan.
  3. Tidak menentukan format output
    Contoh: “Ringkas ini.”
    Bisa jadi paragraf panjang, bukan poin.
  4. Memberi instruksi ganda yang bertentangan
    Contoh: “Buat singkat tapi lengkap dan panjang.”
    AI bingung.

Bagian 6 — Contoh Prompt Siap Pakai untuk Peserta Tunanetra

1. Prompt untuk Belajar

“Jelaskan konsep Machine Learning untuk pemula tunanetra.
Gunakan analogi audio.
Buat dalam 3 paragraf pendek.”

2. Prompt untuk Menulis

“Buatkan pesan WhatsApp untuk meminta izin tidak hadir.
Gunakan bahasa sopan dan singkat.”

3. Prompt untuk Merangkum

“Ringkas teks berikut menjadi 5 poin utama.
Gunakan bahasa sederhana dan ramah screen reader.”

Latihan Praktik

Latihan 1 — Buat Prompt Sendiri

Peserta diminta membuat prompt untuk:

  • Menulis email
  • Merangkum teks
  • Menjelaskan konsep

Latihan 2 — Perbaiki Prompt Buruk

Peserta memperbaiki prompt berikut:

“Tolong jelaskan AI.”

Latihan 3 — Bandingkan Hasil

Gunakan prompt pendek vs prompt lengkap, lalu bandingkan hasilnya.
